# Seguimiento de aprendizaje en Spring Boot

Este repositorio reúne mi progreso de aprendizaje con **Java y Spring Boot**. Su objetivo es conservar, de forma ordenada, los ejercicios, proyectos y conceptos trabajados en cada sesión.

Cada carpeta representa una sesión de estudio y puede contener un proyecto Spring Boot, una práctica específica o scripts relacionados con el tema abordado.

## Objetivos

- Fortalecer fundamentos de Java aplicados al desarrollo backend.
- Crear APIs REST con Spring Boot.
- Practicar persistencia de datos con Spring Data JPA y PostgreSQL.
- Aplicar validaciones, manejo de errores, seguridad y pruebas automatizadas.
- Adoptar buenas prácticas de diseño, organización y documentación de proyectos.

## Estructura del repositorio

```text
.
├── sesion-01/
├── sesion-02/
├── sesion-03/
└── README.md
```

Cada sesión incluirá su propia documentación con los requisitos, la forma de ejecutar el proyecto y los temas aprendidos cuando sea necesario.

## Tecnologías

- Java
- Spring Boot
- Maven o Gradle
- PostgreSQL
- Docker y Docker Compose
- JUnit y Mockito

## Progreso

El contenido se irá agregando gradualmente conforme avance el aprendizaje.
